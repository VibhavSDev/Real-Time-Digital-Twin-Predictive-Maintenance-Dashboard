# Real-Time Digital Twin & Predictive Maintenance Dashboard

A full-stack IoT capstone project simulating an industrial environment.

## Architecture
* **Tier 1 & 3 (Backend):** Java 22, Spring Boot 3, REST/WebSockets
* **Tier 2 (Streaming):** Apache Kafka (KRaft mode)
* **Tier 4 (Frontend):** React.js, WebSockets, Interactive SVG
* **Database:** PostgreSQL
